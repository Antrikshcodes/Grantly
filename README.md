# GRANTLY

A modern scholarship discovery and management experience built for students.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features

- Discover and filter scholarship opportunities
- View eligibility details and deadlines
- Save opportunities and track applications
- Personalize matches with a student profile
- Persist profile, saved scholarships, and tracker data in localStorage
- Responsive interface with Framer Motion scroll and ambient animations

## Stack

Next.js, React, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.
